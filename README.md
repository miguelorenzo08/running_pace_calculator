# Running Pace Calculator

A simple Java console application that calculates running pace and average speed based on distance and time.
Created by athletes, for athletes.
## Features

- Calculate running pace (min/km)
- Calculate average speed (km/h)
- Supports:
    - Hours
    - Minutes
    - Seconds
- Input validation
- Supports decimal distances

## Technologies

- Java
- IntelliJ IDEA
- Git
- GitHub

## Example

Distance: 10 km  
Time: 50 minutes

Result:

- Pace: 5:00 min/km
- Speed: 12 km/h
